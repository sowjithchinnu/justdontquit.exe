Smooth
Fast
Purposeful

CORE PRINCIPLE

Code drives the animation.
The animation should visually explain what the Java code is doing rather than simply displaying the code.

VISUAL LANGUAGE

Variables → clean containers / value boxes
Arrays → physical indexed blocks
Loops → movement / repetition
Stacks → vertical accumulation
Queues → directional flow
Objects → structured entities
Inheritance → hierarchy
Functions → input → transformation → output
Exceptions → branching / error flow
Threads → parallel motion
Real-world concepts → transition naturally into Java representations

COMPOSITION

Large readable elements
Generous margins
Clean grid-based layouts
Strong visual hierarchy
One primary focal point at a time
Minimal on-screen text
Clear separation between:
Hook → Concept → Code → Visualization → Result
Keep important content inside Instagram-safe areas.

SIGNATURE

Real-world problem → Java code → code execution → visual result
Whenever appropriate, use the transition:
Code → highlight → execution → visual representation

✓ Reuse consistent visual metaphors
✓ Keep scenes focused
✓ Maintain her existing visual identity
